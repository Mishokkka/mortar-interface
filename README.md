# FBL Mortar Interface

Standalone module for Forbidden Lands 13.0.5 on Foundry VTT 13.351.

Current version: 0.3.4

## Quick Access integration

The module remains standalone. When Forbidden Lands Quick Access 1.7.25+ is active, Mortar reuses its public Talent/Spell tooltip API for the custom AUXILIARY ROUTINES rows and maps Quick Access sheet widgets onto the active Mortar color palette. The native FBL/Quick Access character header is left intact rather than rebuilt.
